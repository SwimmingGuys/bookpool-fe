# 공지사항 & 문의/요청 명세서

## 배경
- Header의 "공지사항" 링크가 라우트 없이 죽어 있어 페이지 추가가 필요하다.
- 사용자와 관리자 간 소통 채널을 만든다.

## 범위
- 공지 목록 `/notice` — 공개
- 공지 상세 `/notice/:id` — 공개
- 문의/요청 `/support` — 로그인 필요
- 어드민 관리 화면은 범위 외 (mock 데이터로 표현)

## 기능

### 관리자 → 사용자 (공지)
- 업데이트·정책·점검·이벤트 등 공지 표시
- 중요 공지 상단 고정
- 목록 페이지네이션

### 사용자 → 관리자 (문의/요청)
- 요청·문의 작성 (유형 / 제목 / 내용)
- 내 문의 내역과 상태(대기 / 답변완료) 확인

## 데이터
- 공지: `TODAY_DATE` 기준 결정적 mock 데이터
- 문의: 사용자별 localStorage 저장 (기존 per-user 스토어 패턴 재사용)

## 완료 기준
- Header "공지사항" 링크 정상 동작
- 목록 페이지네이션 + 고정 공지 상단 표시
- 목록 ↔ 상세 이동, 잘못된 id 안전 처리
- 비로그인 문의 접근 시 로그인 후 원래 경로로 복귀
- 변경 파일 eslint 통과
